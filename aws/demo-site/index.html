How the research system works

Designed to test whether rapid sensor evidence can support more robust estimation and controlled recovery—without assuming the measurements are always trustworthy.

01 / PERCEPTION

Event-driven sensing

Asynchronous event-camera simulation provides changes in the scene rather than relying only on periodic frames.

02 / ESTIMATION

Evidence before confidence

The observer distinguishes quiet, unobserved, contradictory, and corrupt evidence while tracking uncertainty.

03 / CONTROL

Recovery under constraints

An LQR controller and safety-shield model are exercised against a simulated unstable cart-pole plant.

Evidence, not marketing claims

The repository exposes the tests and experimental methods so reviewers can inspect what has and has not been demonstrated.

What can be inspected

Unit and integration tests, seeded sensor-fault simulations, registered pilot comparisons, dependency/SBOM scans, CPU timing audit and source-release verification.

View test workflows and artifacts ↗

Evaluation methodology

Fixed seeds, paired D versus D-ev geometry/evidence baselines, documented confidence intervals and a distinct final holdout that is not used for early tuning.

Read the scientific protocol ↗

Current limitations

This website is a static research showcase. It does not perform inference or control a physical device. Full neural-assisted model comparisons, long-horizon held-out results, physical hardware trials, and production deployment safeguards remain ongoing work.
